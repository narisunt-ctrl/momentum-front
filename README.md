# MOMENTUM FRONT · แนวหน้าไม่หยุดนิ่ง

เกมรถถัง 3D เล่นบนเบราว์เซอร์ หลายผู้เล่นบนเครื่องเดียว (จอแยก 1–4 คน + บอท AI สูงสุด 6 คัน) ที่ **รถถังห้ามหยุด** และมี **AI ควบคุมการยิง (FCS-AI)** ช่วยวิเคราะห์การเคลื่อนที่ของเป้า คำนวณมุมยิง และบอกโอกาสถูกเป้าแบบเรียลไทม์

A browser-based 3D tank battle for 1–4 local players plus AI bots. Tanks can never stop, shells follow real ballistics, and an AI fire-control computer tracks targets with a Kalman filter, solves the firing angle and lead, and estimates hit probability.

> สร้างโดย **นริสันต์ นาคะเกศ (Narisan Nakakes)** · แรงบันดาลใจจากโปรเจกต์ [choubari/3D-Tanks-Game-Unity](https://github.com/choubari/3D-Tanks-Game-Unity) (Unity *Tanks!* tutorial) — เกมนี้เขียนใหม่ทั้งหมด ไม่ได้ใช้โค้ด โมเดล หรือเสียงจากต้นฉบับ

## โหมดออนไลน์ข้ามเครื่อง

1. โฮสต์ใส่ชื่อ → **สร้างห้อง** → ได้รหัส 5 ตัวและลิงก์ `?join=XXXXX`
2. เพื่อนเปิดลิงก์ (หรือพิมพ์รหัส) → ใส่ชื่อ → **เข้าร่วม** — แต่ละคนเล่นจากเครื่องตัวเอง ใช้คีย์บอร์ด+เมาส์หรือจอย
3. โฮสต์ตั้งโหมด จำนวนบอท ระดับ FCS แล้วกด **เริ่ม** — รวมได้สูงสุด 8 คัน (โฮสต์ยังเล่นจอแยกในเครื่องตัวเองเพิ่มได้)

เทคนิค: WebRTC data channel ผ่าน [PeerJS](https://peerjs.com) (ใช้ signaling/TURN สาธารณะของ PeerJS ไม่ต้องมีเซิร์ฟเวอร์ของเราเอง) แบบ **host-authoritative** — โฮสต์จำลองโลกทั้งหมด (รวมบอทและฟิสิกส์กระสุน) ผู้เล่นอื่นส่งสถานะคอนโทรลเลอร์ 30 ครั้ง/วินาที โฮสต์ส่ง snapshot 20 ครั้ง/วินาที (รถถัง กระสุน วงปืนใหญ่ อาคาร กล่องเสบียง เอฟเฟกต์ และข้อมูล FCS ส่วนตัวของแต่ละคน) เครื่องลูก interpolate ให้ลื่น และสร้างภูมิประเทศจาก seed เดียวกัน ถ้าผู้เล่นหลุด AI จะขับรถคันนั้นต่อ

ทดสอบ 2 แท็บในเครื่องเดียวได้ด้วย `index.html?net=local` (ใช้ BroadcastChannel แทน WebRTC)

> หมายเหตุ: บางเครือข่ายองค์กร/โรงเรียนบล็อก WebRTC — ถ้าเชื่อมต่อไม่ได้ให้ลองเน็ตมือถือ

## บอทขับด้วย Reinforcement Learning

บอทที่ชื่อขึ้นต้นด้วย **NN-** ขับรถด้วยโครงข่ายประสาทเทียม (MLP 22-32-24-2, 1,578 พารามิเตอร์) — ตัดสินใจเลี้ยวและเปลี่ยนเกียร์เอง ส่วนการยิงยังใช้ FCS-AI ตัวเดียวกับผู้เล่น

- **อินพุต 22 ค่า:** ทิศ/ระยะ/ความเร็วของเป้า (จาก Kalman tracker ไม่ใช่ค่าจริง), ป้อมศัตรูหันมาหาเราไหม, ศัตรูหันด้านไหนให้เรา, ทิศและระยะถึงวงปลอดภัย, ความเร็วตัวเอง, เซนเซอร์ระยะสิ่งกีดขวาง 5 ทิศ, คำเตือนถูกล็อก, HP, และ oscillator 2 ตัวให้หักหลบเป็นจังหวะได้
- **ขั้นที่ 1 Behaviour cloning:** เลียนแบบบอทสคริปต์เพื่อให้ขับเป็นก่อน
- **ขั้นที่ 2 Evolution Strategies** (OpenAI-ES, antithetic sampling, rank shaping, Adam) — แข่งกับบอทสคริปต์ในสนามจำลองแบบไม่มีกราฟิก (`rl/env.js` ใช้กติกาเดียวกับเกม) โดยคู่ต่อสู้เก่งขึ้นเรื่อยๆ (curriculum) รางวัล = ดาเมจที่ทำได้ − ดาเมจที่โดน×1.4 + kill + รอดชีวิต − อยู่นอกวง − ชนสิ่งกีดขวาง
- ผลการฝึก (80 รุ่น, ~13 นาที): บน 64 สนามที่ไม่เคยเห็น 1 คัน vs บอทสคริปต์ 2 คัน — NN ชนะ 36% vs สคริปต์ 34%, โดนดาเมจน้อยกว่า (92 vs 99), fitness 33 vs 23 · **ตอนนี้เก่งพอๆ กับบอทสคริปต์ ยังไม่ทิ้งห่าง** ฝึกต่อด้วย `--resume` เพื่อพัฒนาได้ (รายละเอียด `rl/evaluation.txt`, `rl/training-log.csv`)

```bash
node rl/train.js 80          # ฝึกใหม่ 80 รุ่น (ประมาณ 30–40 นาที บน 2 คอร์)
node rl/train.js 40 --resume # ฝึกต่อจาก checkpoint
node rl/evaluate.js          # เทียบ NN กับบอทสคริปต์บน 64 สนามที่ไม่เคยเห็น
```

## FCS-AI ทำงานยังไง (`js/fcs.js`)

1. **ติดตามเป้า (MotionTracker)** — Kalman filter แบบ constant-velocity ต่อแกน รับตำแหน่งจากเซนเซอร์ที่มีสัญญาณรบกวนตามระยะ และต้องมองเห็นจริง (ภูเขา อาคาร ควัน บังได้) เมื่อเป้าหายไปจะ "coast" จากความจำ
2. **วิเคราะห์การเลี้ยว** — fit สมการกำลังสองแบบ least-squares กับตำแหน่ง 1.2 วินาทีล่าสุด ได้ความเร็วและความเร่ง → อัตราเลี้ยว ω = (v × a)/|v|² ใช้ทำนายเส้นทางโค้ง
3. **ดัชนีการหลบ (manoeuvre index)** — วัดว่าเป้าเปลี่ยนความเร็ว/ทิศแค่ไหน ใช้ขยายความไม่แน่นอนของการทำนาย → ยิ่งคุณหักหลบ Pk ของศัตรูยิ่งตก
4. **คำนวณการยิง (solveFiring)** — จำลองวิถีกระสุนจริง (gravity + quadratic drag + wind) แล้ววนหา มุมยกปืน (secant method) และมุมทิศ (แก้ลมข้าง) จนกระสุนไปถึงจุดที่เป้าจะอยู่ ณ เวลาเดินทาง (time of flight) — ได้ yaw, pitch, lead, ToF
5. **โอกาสถูกเป้า (hitProbability)** — Monte-Carlo สุ่มตำแหน่งเป้าจาก covariance ของ Kalman รวมกับการกระจายของปืน (มากขึ้นเมื่อยิงขณะวิ่ง) และความคลาดเคลื่อนของการวางปืนตอนนี้
6. **Masking** — ตรวจว่าวิถีกระสุนจะชนเนินหรืออาคารก่อนถึงเป้าหรือไม่

ระดับการช่วยเหลือ: **Auto-lay** (กดค้าง LOCK แล้ว AI หมุนป้อม/ยกปืนให้ตามความเร็วกลไกจริง คุณกดยิงเอง) · **Advisor** (แสดงค่าอย่างเดียว) · **Off** (เล็งเองล้วนด้วยวิถีกระสุน)

บอททุกคันใช้ FCS ตัวเดียวกัน แต่มีความผิดพลาดของพลยิง เวลาตอบสนอง และเกณฑ์ Pk ก่อนยิงตามระดับความเก่ง และจะหักหลบหนักขึ้นเมื่อถูกล็อก

## โครงสร้าง

```
index.html          เมนู, ล็อบบี้ออนไลน์, โหลด Three.js / PeerJS
js/fcs.js           ระบบ AI ควบคุมการยิง (คณิตศาสตร์ล้วน ใช้ได้ทั้งเบราว์เซอร์และ Node)
js/game.js          ตัวเกม: ภูมิประเทศ, รถถัง, กระสุน, เกราะ, บอท, จอแยก, เสียง, netcode
js/net-transport.js WebRTC (PeerJS) และ BroadcastChannel transport
js/rl-policy.js     โครงข่ายประสาท + ฟังก์ชันอินพุต (ใช้ร่วมกันทั้งเกมและตัวฝึก)
js/rl-weights.js    น้ำหนักที่ฝึกแล้ว
rl/env.js           สนามจำลองไร้กราฟิกสำหรับฝึก
rl/train.js         Behaviour cloning + Evolution Strategies
rl/evaluate.js      ประเมินผลเทียบบอทสคริปต์
tests/fcs.test.js ทดสอบความแม่นยำการยิงใส่เป้านิ่ง/วิ่งตรง/วิ่งวงกลม ทั้งมีและไม่มีลม
docs/DESIGN.md    แนวคิดการออกแบบเกม
```

